# DataAgent 公司母版 PPT 设计分析

> 源文件：`公司母版PPT 2025.12.31.pptx`（178MB，**未入库存储**，见文末说明）
> 品牌：DataAgent / 北京数智分身科技有限公司（www.DataAgent.cc）
> 定位语：让全球企业拥有 AI 原生组织的操作系统
> 分析日期：2026-09-17

## 一句话评价

这是一套**重版式系统**的企业级母版：98 个版式覆盖封面、目录、章节页、双栏、多图矩阵等场景，深蓝主色 + 超大号数字编号是它最强的视觉记忆点，和麦肯锡风的"理性克制"路线高度兼容，很适合作为我们 HTML 幻灯片的 UI 参考。

## 配色系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色（深蓝） | `#004080` | 封面底色、标题、强调 |
| 辅助蓝 | `#00549F` | 次级强调 |
| 亮蓝 | `#3399FF` | 点缀、超链接、高亮 |
| 中蓝 | `#0066B3` | 图表辅色 |
| 辅助绿 | `#2E7D32` | 正向数据/结论 |
| 警示红 | `#CC0000` | 风险/负向数据 |
| 深色文字 | `#1A1A1A` | 正文 |
| 浅灰 | `#C6C6C6` | 副标题、弱化信息 |
| 背景 | `#FFFFFF` | 内容页白底 |

特点：**封面深蓝天白字，内容页白底深蓝天**——明暗两条线，章节转换有节奏感。

## 字体系统

| 层级 | 西文 | 中文 |
|---|---|---|
| 标题 | Arial Black / Saturday Sans Regular | 阿里巴巴普惠体 3.0 75 SemiBold |
| 正文 | Arial | 阿里巴巴普惠体 3.0 45 Light |

HTML 实现时的降级方案：`"Alibaba PuHuiTi", "PingFang SC", "Microsoft YaHei", sans-serif`。

## 画布与字号

- 画布 40×22.5 英寸（标准 16:9 的 **3 倍放大**，即 36576000×20574000 EMU），字号除以 3 即标准 16:9 的等效值
- 目录页字号梯队（括号内为标准等效值）：
  - "目录"大字 120pt（≈40pt）
  - 章节编号 "01/02/03/04" **150pt（≈50pt）超大号数字**——核心视觉锤
  - 章节标题 42pt（≈14pt）
  - 说明文字 30pt（≈10pt）
- 章节页：英文品牌词 "DATAAGENT" 110pt 压阵 + 主张句 82pt + 英文副题 44pt
- 页脚系统：24pt 小字「机密文件・公司名・网址」三件套

## 版式系统（98 个版式）

- **编号族版式**（1_ 到 52_）：每个编号含 Title Slide / Title+Subtitle+Bullets / 空白 三件套，对应不同章节或不同品牌的变体
- **目录页**：左侧巨型"目录"二字 + 4 列网格排布章节，每列 = 超大编号 + 标题 + 说明
- **图片版式**：Single / 2-up / 3-up … 8-up 图片矩阵，适合案例墙、截图展示
- **双栏版式**：左右均分 17.7in 栏宽，适合对比、图文并列
- **Use Case / Image w/ Text** 等业务场景版式

## 可复用的设计决策

1. **超大编号做视觉锚点**：章节编号放到 50pt 等效以上，编号本身就是装饰
2. **明暗交替节奏**：深蓝封面/章节页 + 白色内容页，翻页时有"换气"感
3. **三件套页脚**：密级・公司・网址，小字号浅灰，咨询报告的规范感
4. **克制的语义色**：绿=正向、红=风险，只在数据场景出现，不做装饰
5. **中英混排分层**：英文品牌词超大号做图形化元素，中文主张句次之
