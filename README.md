# ppt-design

沉淀优秀 PPT 案例与设计提示词，并用 HTML/CSS 产出高质量网页幻灯片。

## 目录结构

```
references/   优秀 PPT 案例及分析笔记（notes/）
prompts/      PPT 设计提示词库
slides/       产出的 HTML 幻灯片项目（每个任务一个子目录）
```

## 使用方式

- 查看幻灯片：浏览器直接打开 `slides/<任务名>/index.html`
- 导出 PDF：浏览器打印（Cmd/Ctrl + P），目标选"另存为 PDF"，无边距
- 详细工作约定见 [CLAUDE.md](CLAUDE.md)
